## 原创示意图

六代章节的“技术流程示意”以 `app.js` 内联 SVG 代码绘制，属于本项目原创简化图，不是运营商拓扑、精确标准图或某起真实故障的记录。6G未来城市图由 `assets/css/history-media.css` 中的 CSS 图形绘制，属于未来情境设计，不是照片、扫描模型或商用设备。6G仍处于研究与发展阶段。

## 素材分类约定

- 1G–4G：真实终端产品照片，均为后期拍摄；不将产品照标作当年现场历史照片。
- 5G：现代工业环境照片，明确标注为场景参考，不能据此推断5G部署。
- 6G：项目原创未来概念图；没有使用AI生成图冒充历史照片。
- 六代流程图：项目原创技术原理示意图。
